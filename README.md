# 📱 Unit Converter App

A modern Android application built using **Kotlin** and **Jetpack Compose** that enables users to perform fast, accurate, and user-friendly unit conversions across multiple measurement categories.

> Designed as a learning project to explore Android development, declarative UI with Jetpack Compose, and state management.

---

## ✨ Features

- 📏 Convert between different measurement units
- ⚡ Instant conversion results
- 🎨 Clean and modern Jetpack Compose UI
- 🔽 Easy-to-use dropdown menus
- ✅ Input validation for numeric values
- 📱 Responsive design for Android devices
- 🚀 Lightweight and fast performance

## 🚀 Getting Started

### Prerequisites

- Android Studio Hedgehog or later
- JDK 17+
- Android SDK

### Installation

```bash
git clone https://github.com/IndushreeDN/Unit-Convertor.git
```

Open the project in Android Studio.

Sync Gradle.

Run the application on:

- Android Emulator
- Physical Android Device

---

## 📖 How It Works

1. Enter the value to convert.
2. Select the input unit.
3. Select the output unit.
4. Tap the Convert button.
5. View the converted result instantly.
